# Analytics and export

Open **Administration → Analytics** for organization-wide workflow metrics.

The report covers workflows started in the selected period: 7, 30, or 90 days. You can narrow it to one published request type.

Figures are recalculated at most every 10 minutes; the time under the title shows when. Choose **Refresh** to recalculate now. The dashboard's administrator cards use the same figures.

## What you will see

- Items waiting on you, overdue work, median cycle time, return rate, and SLA compliance
- Daily activity
- Bottleneck steps
- Workload by approver
- Longest-waiting active workflows
- Reportable custom-field breakdowns for the selected request type

Charts have a text summary and a table so the same numbers work without colour.

## Export

Export CSV, Excel, or PDF from the same filters you have on screen. Sensitive field values stay out of unauthorized exports. Export downloads are rate limited. CSV and Excel keep text as text so spreadsheet applications do not run request content as formulas.

Use analytics to find stuck steps and overloaded approvers. It is not a substitute for the audit trail on a single request.
